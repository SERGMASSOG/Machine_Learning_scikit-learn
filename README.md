# Machine_Learning_scikit-learn

## 📘 Introducción
Este repositorio reúne proyectos y laboratorios de **Machine Learning** aplicados con **scikit-learn** y herramientas complementarias de análisis de datos. El objetivo es construir flujos de trabajo robustos, reproducibles y bien documentados que reflejen las mejores prácticas de un científico de datos y un machine learning engineer.

## 🎯 Objetivos del proyecto
- Implementar **procesos completos de modelado**: desde la exploración inicial de datos (EDA) hasta la validación de modelos.
- Aplicar **transformaciones y preprocesamiento** de datos con técnicas modernas.
- Construir **pipelines escalables** que integren imputación, codificación y escalamiento.
- Evaluar modelos con métricas adecuadas y validación cruzada para garantizar resultados confiables.

## 🛠️ Tecnologías y librerías
- **Python 3.x**
- **scikit-learn** para modelado y pipelines
- **pandas** y **numpy** para manipulación de datos
- **matplotlib** y **seaborn** para visualización
- **Jupyter Notebooks** para documentación y experimentación interactiva

## 🔍 Flujo de trabajo
1. **Exploratory Data Analysis (EDA)**  
   - Análisis descriptivo de variables.  
   - Visualización de distribuciones y correlaciones.  
   - Identificación de outliers y valores faltantes.

2. **Preprocesamiento de datos**  
   - **Imputación** de valores faltantes (media, mediana, KNNImputer).  
   - **Codificación categórica** con One-Hot Encoding.  
   - **Escalamiento** de variables numéricas (StandardScaler, MinMaxScaler).  
   - **Transformaciones polinomiales y regularización** (Lasso, Ridge).

3. **Construcción de pipelines**  
   - Integración de pasos de preprocesamiento y modelado en un flujo único.  
   - Reutilización y reproducibilidad garantizadas.  
   - Ejemplos con regresión, clasificación y clustering.

4. **Modelado y entrenamiento**  
   - Algoritmos implementados:  
     - Regresión lineal y polinomial  
     - Regresión logística  
     - Árboles de decisión y Random Forest  
     - K-Nearest Neighbors (KNN)  
     - Clustering (K-Means, DBSCAN)  

5. **Evaluación y validación**  
   - Métricas de regresión: RMSE, MAE, R².  
   - Métricas de clasificación: Accuracy, Precision, Recall, F1-score, ROC-AUC.  
   - Validación cruzada y GridSearchCV para optimización de hiperparámetros.

## 📂 Estructura del repositorio
